# Storage

## Cloud and On-Prem Storage

NYPL must store one copy of every file managed by Preservica on storage owned and managed by the Library.

NYPL may store additional copies of files on cloud storage services.

## Storage Based on Usage

Preservation representations must be stored in three distinct locations.
Preservation storage should prioritize cost efficiency over retrieval speed.

Access representation should be stored in two locations.
Access storage should prioritize retrieval speed requirements for access systems.
