# Ingest

## Ingest Eligibility

Preservica may only be used for the storage of NYPL collections and files supporting their management.

The following categories encompass all eligible files for ingest.

- Born-digital acquired and accessioned by the Research Libraries
- Digitized representation of collections, including still images, media files, and 3D scans

## Ingest Requirements

Files submitted for ingest must be in standardized packages.
Packaging requirements include:

- foldering schemes
- file format requirements
- fixity information
- at least one external identifier

The exact specifications are created in collaboration with the program responsible for producing the packages.

### Updates to Requirements

Updates to specifications must be agreed upon by both the Digital Repository team and the program responsible for producing packages before being placed into production.

Updates must take into account:

- changes required for the production workflow
- changes required for the ingest workflow

## Ingest Process Responsibilities

The Digital Repository team is responsible for managing the ingest process, including submission, validation, reporting, and troubleshooting.

Source programs may be responsible for submitting new materials for ingest.
