# Metadata

## Allowances for Types of Metadata

The following types of metadata must be stored in Preservica:

- identifiers linking Preservica objects to records in other systems

The following types of metadata may be stored in Preservica:

- provenance data describing the origin of files
- technical information describing the characteristics of files
- qc information describing the quality characteristics of files
- rights information that enforces staff access restrictions

The following types of metadata must not be stored in Preservica:

- descriptions of the content of files

Preservica must not be used to store descriptive metadata, including values synced from descriptive metadata systems.

## Minimum Metadata Requirements

Every object managed by Preservica must have metadata that relates it to at least one other NYPL system.

For digitized objects, the identifier must be an object ID issued by SPEC.

For born-digital objects, the identifier may be an object ID issued by SPEC.

Every object managed by Preservica should have an identifier that relates it to a descriptive record.
