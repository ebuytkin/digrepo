# Access

## User Administration

### Staff Access

Access to the Preservica graphical interfaces is managed according to ActiveDirectory Groups and Preservica roles.

The Digital Repository is responsible for designing ActiveDirectory Groups and applying them to Preservica roles.
IT is responsible for implementing and updating the groups over time.

Groups should be designed in order to use automated user mappings when possible.

### API Access

Access to the Application Programming Interface requires a service account issued and administered through Preservica.

The Digital Repository team is responsible for issuing and managing API accounts.

### Public Access

The Digital Repository team is responsible for supporting any decisions around public access to the Preservica Portal.
